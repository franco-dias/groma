Para o seu agente de código

Ajuste na página, deixe o agente escrever

{{ d.agent }}

Mude tamanhos, espaçamentos, cores e textos direto na página. O Groma lista cada edição como antes → depois e entrega a lista para o seu agente de código. Ele descreve a mudança e deixa o código com o agente.

01

Edite na página

Dê dois cliques num valor do painel ou arraste um número, e a página muda na hora. Dois cliques num texto da página deixam você reescrever ali mesmo.

padding-top: 12px → 16px
02

Copie as edições

Um botão na aba Edits copia tudo como texto: cada elemento, como achá-lo e o que mudou, com o token que guarda o novo valor.

- `padding-top`: `12px` → `16px`
03

Ou deixe o agente buscar

Adicione este comando ao seu agente como servidor MCP e ele lê as edições ao vivo, sem copiar e colar. Num app com servidor de desenvolvimento próprio, adicione também o script da ponte ao build de desenvolvimento, ao lado do Groma. Roda na sua máquina e só aceita páginas locais.

npx gromajs mcp
<script src="http://localhost:4777/bridge.js"></script>

Comece

Três jeitos de usar

{{ d.ways }}
01

Rode num arquivo

Abre a página com o Groma. Não instala nada no seu projeto nem mexe no arquivo. Precisa do Node.js 18.3 ou mais recente.

npx gromajs your-page.html
02

Adicione o script

Coloque como primeira tag dentro do <head>. Funciona num arquivo aberto do disco e numa página servida.

<script src="https://cdn.jsdelivr.net/npm/gromajs@1.0.2/dist/groma.js"></script>
03

Configure

Escolha como os valores copiados saem: "css" (o padrão) ou "sx".

Groma.configure({ copyFormat: "sx" })

Atalhos

Segure ⌥ OptionAlt e veja

{{ d.keys }}

Prefere não segurar tecla? A pílula no canto inferior direito deixa o modo de inspeção ligado.O Groma precisa de teclado e de mouse ou trackpad, então abra esta página num computador para testar.

⌥ OptionAlt+passar o mouse
Inspecionar. O box model e uma etiqueta com o nome e o tamanho do elemento.
⌥ OptionAlt+clique
Fixar. Abre o painel lateral nele. Passe o mouse em outro elemento para medir.
⌥ OptionAlt+clique direito
Camadas. Um menu com todas as camadas sob o ponteiro.
⌥ OptionAlt+↑ ↓ ← →
Navegar. Move a seleção para o pai, o primeiro filho e os elementos ao lado.
dois cliques
Editar. Num valor do painel, ou num texto da página com o modo de inspeção travado.
⌥ OptionAlt+Shift+G
Painel. Abre ou fecha o painel lateral.
Espaço+arrastar
Mover. Arrasta o canvas.
