Inspect

hover
Box model of the element under the pointer, with a chip that names it.
click
Pin the element. The panel opens on it.
hover
With an element pinned: distances from it to the hovered element, in red.
right-click
List every layer under the pointer, to reach one that sits behind another.
Inspect pill
Bottom right. Click it to lock inspect mode on, so none of this needs .
Esc
Turn the inspect lock off, and end a comparison.

Copy

Click a value
Copies it. A size, a colour, a font weight: anything shown in monospace.
Click a token
Copies the token. Its theme path, its variable and its value in each theme copy separately.
Click “margin” or “padding”
In the box diagram: copies all four sides at once.
Click a component name
Copies the name. Each prop value copies on its own.
Click a class
Open the class list first; each chip copies its class.

Specs

px · rem
Switch the unit lengths are shown and copied in.
Grid
Lay a 4 or 8 pixel grid over the element's board.
Compare
Makes the pinned element the baseline. Pin another to see only what differs.
Copy link
A link that reopens this page with the element pinned. Paste it in a ticket.
Pick colour
Pick any pixel on screen and see which token has that colour.
Breadcrumb
Click the parent's name to pin the parent.
fixed · hug · fill
Beside the size: whether each axis has a set size, follows its content or fills its parent.
No token
A colour written by hand that no token has. Ask the designer before you hard-code it.

All CSS

Type over a value
Changes it on the page. Enter or clicking away saves; Esc cancels.
↑ ↓
Change a number by 1. With Shift by 10, with by 0.1.
↩ on a row
Removes your edit and puts back the page's own value. Clearing the value does the same.
Enter
In the content box at the top: apply the new text.
Search
Filters properties by name. “Hide defaults” off shows every property.
Your edits
Are saved in this browser for this page and come back on reload. They never change the file.

Layers and panel

Hover a layer
Outlines it on the page. Click to pin it; the arrow opens its children.
Drag the left edge
Resizes the panel. The width is remembered.
» menu
This reference, “Push the page aside” and “Collapse panel”. Click the collapsed rail to bring the panel back.
Push the page aside
On by default: the panel takes its width out of the page instead of covering it. Switch it off if a page looks wrong pushed, for example one with elements fixed to the right edge. Your choice is remembered.
Changes tab
On a Claude Design export: pick an older export to list the boards that changed.

Good to know

Sizes and distances
Are in the design's own pixels, whatever the zoom of the board.
Boards that look empty
Some exports draw a board only when it scrolls into view. Scroll to it first.
Props
Are listed as the design passes them. Check them against your own component before you use them.
